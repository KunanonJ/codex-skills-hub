### Tracking Losses or Deductions Suspended by Other Provisions

#### QBI Loss Tracking Worksheet

Use the QBI Loss Tracking Worksheet to monitor suspended losses separately for each suspending provision. All losses should be entered as negative numbers.

#### Column Instructions

**Column A -- Total Suspended Losses in Year of Disallowance**

  * Rows 1a--1g: Enter suspended losses by year, starting with pre-2018 losses.
  * Add rows as needed for future years after row 1g.
  * Allocate between Non-QBI (Column E) and QBI (Column I).
  * **Note.** All pre-2018 losses allocate to Non-QBI.

**Column B -- QBI Fixed Percentage**

  * Divide Column I by Column A for each year.
  * Enter the resulting percentage in the corresponding year row.

**Column C -- Prior Year Suspended Losses Allowed**

  * Rows 1b--1g: Enter any prior year suspended losses allowed in the corresponding year row.
  * Add rows as needed after row 1g for future years.
  * **Note.** Total in Column C, row 2, cannot exceed total in Column A, row 2.

**Column D -- Allowed Losses Limited by Other Code Sections**

When a prior year suspended loss allowed under one code section is subsequently limited by another code section, do NOT include it in QBI calculation until allowed in taxable income. Instead, add it to total suspended losses in the year of disallowance under the new limiting code section. Column D and Row 3 address this situation.

In Column D, enter the amount of any prior year suspended losses allowed under this code section but subsequently disallowed under another code section, entered on the row for the year the loss was allowed under this code section. These amounts are allocated between Non-QBI and QBI in Columns G and K for the corresponding year (see Row 3 below).

**Column E -- Non-QBI Suspended Losses**

  * Rows 1a--1g: Enter suspended losses allocable to Non-QBI into the appropriate year row.
  * Pre-2018 losses in row 1a; 2018 in row 1b; 2019 in row 1c; etc.
  * Add rows as needed after row 1g for future years.

**Column F and Column J -- Allocated Prior Year Suspended Losses Allowed**

  * Column F: Non-QBI allocated prior year suspended losses allowed.
  * Column J: QBI allocated prior year suspended losses allowed.
  * Use First-In-First-Out (FIFO) method for allocation.
  * Allocate first to pre-2018 losses (row 1a) until exhausted -- all are Non-QBI.
  * Then allocate based on QBI Fixed Percentage (Column B) for each subsequent year.

**Column G and Column K -- Utilized Amounts**

  * Column G: Shows how Non-QBI allocated prior year suspended losses are utilized each year.
  * Column K: Shows how QBI allocated prior year suspended losses are utilized each year.
  * Example: Column F, row 1b, must tie to Column G(i), row 2; Column F, row 1c, must tie to Column G(ii), row 2.
  * Add columns as needed using naming format G(i)--G(vii) and K(i)--K(vii).

**Column H -- Remaining Non-QBI Suspended Losses**

For each row: Column E minus amounts utilized in Columns G(i) through G(vii). Result cannot exceed zero.

**Column I -- QBI Suspended Losses**

  * Rows 1b--1g: Enter suspended losses allocable to QBI into the appropriate year row.
  * 2018 losses in row 1b; 2019 in row 1c; etc.
  * Add rows as needed after row 1g for future years.

**Column L -- Remaining QBI Suspended Losses**

For each row: Column I minus amounts utilized in Columns K(i) through K(vii). Result cannot exceed zero.

#### Allocation Steps for 2018 Losses

**Step 1.** Allocate prior year suspended losses from Column C, row 1b, up to total suspended losses in Column A, row 1a, to Column F, row 1b.

**Step 2.** If losses remain after Step 1:

  * For QBI allocation: Multiply remaining losses (up to Column A, row 1b) by Column B, row 1b, and enter in Column J, row 1b.
  * For Non-QBI allocation: Multiply remaining losses (up to Column A, row 1b) by (100% minus Column B, row 1b), and add to Column F, row 1b.

**Step 3.** Follow instructions for Columns G, K, H, and L for rows 1a and 1b.

#### Allocation Steps for 2019 Losses

**Step 4.** (Skip if Column C, row 1c, is zero.) Allocate prior year suspended losses from Column C, row 1c, up to remaining suspended losses in Column H, row 1a, to Column F, row 1c.

**Step 5.** (Skip if Column C, row 1c, is zero.) If losses remain after Step 4, using FIFO method:

  * For QBI: Multiply remaining losses (up to sum of Column H, row 1b, plus Column L, row 1b) by Column B, row 1b, and enter in Column J, row 1c.
  * For Non-QBI: Multiply remaining losses (up to sum of Column H, row 1b, plus Column L, row 1b) by (100% minus Column B, row 1b), and add to Column F, row 1c.
  * If losses persist, multiply remaining losses (up to sum of Column H, row 1c, plus Column L, row 1c) by Column B, row 1c, and add to Column J, row 1c.
  * Then multiply remaining losses (up to sum of Column H, row 1c, plus Column L, row 1c) by (100% minus Column B, row 1c), and add to Column F, row 1c.

**Step 6.** Follow instructions for Columns G, K, H, and L for rows 1a through 1c.

#### Allocation Steps for 2020 and Beyond

Repeat Steps 4 through 6, adjusting as necessary for Column C, row 1d, and each subsequent row.

#### Row 3 -- Allocation of Allowed Losses Limited by Other Code Sections

**For 2018 (Row 1b):**

  * For QBI (Column K(i), Row 3): Column D, row 1b, multiplied by (Column K(i), row 2 divided by (Column K(i), row 2 plus Column G(i), row 2)).
  * For Non-QBI (Column G(i), Row 3): Column D, row 1b, multiplied by (Column G(i), row 2 divided by (Column G(i), row 2 plus Column K(i), row 2)).

**For 2019 (Row 1c) and beyond:**

Continue computation for Columns K(ii) and G(ii) through K(vi) and G(vi), multiplying the percentage times:

  * Column D, row 1c, for 2019
  * Column D, row 1d, for 2020
  * Column D, row 1e, for 2021
  * Column D, row 1f, for 2022
  * Column D, row 1g, for 2023

For tax years after 2023, add additional rows and columns using the same naming and computation format.

#### Row 4 -- Total Prior Year Suspended Losses Allowed to Be Included in QBI

The amounts in Columns K(i) through K(vii), row 4, equal the loss amounts that must be included in your current year QBI for each respective year as losses from separate trades or businesses.

### Paperwork Reduction Act Notice

The estimated burden for completing Form 8995 is:

  * **Individual filers:** 4 hours, 43 minutes (OMB control number 1545-0074)
  * **Tax-exempt filers:** (OMB control number 1545-0047)
  * **Business filers:** (OMB control number 1545-0123)
  * **Trust filers:** (OMB control number 1545-0092)

Estimated time includes:

  * Recordkeeping: 4 hrs., 43 min.
  * Learning about the law or the form: 51 min.
  * Preparing, copying, assembling, and sending the form to the IRS: 2 hrs., 6 min.

Form 8995-A has higher burdens: 7 hrs., 52 min. recordkeeping; 1 hr., 53 min. learning; 6 hrs., 6 min. preparing, copying, assembling, and sending.

The time needed to complete and file this form varies depending on individual circumstances. Books or records relating to the form or instructions must be retained as long as their contents may become material in administering Internal Revenue laws. Generally, tax returns and return information are confidential per Internal Revenue Code section 6103.

Comments concerning accuracy of time estimates or suggestions for simplification may be submitted to the IRS.
