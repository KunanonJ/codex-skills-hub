# W-2 Box 14 Codes

Box 14 entries vary by employer and state. Some are deductible state taxes, while many others are only informational.

## Common deductible state payroll taxes

| Code | Description | State | Typical treatment |
|---|---|---|---|
| SDI / CASDI | State Disability Insurance | CA | Often treated as a state income tax item on Schedule A |
| CAPFL / PFL / CAFPL | Paid Family Leave | CA | Often treated with other deductible state payroll taxes |
| NJSDI / NJ SDI | State Disability Insurance | NJ | Often treated as a state income tax item on Schedule A |
| NJFLI / NJ FLI | Family Leave Insurance | NJ | Often treated as a state income tax item on Schedule A |
| NYPFL | Paid Family Leave | NY | Often treated as a state income tax item on Schedule A |
| NYSDI | State Disability Insurance | NY | Often treated as a state income tax item on Schedule A |
| PASUI | State unemployment insurance, employee share | PA | Often treated as a state income tax item on Schedule A |
| RISDI | Temporary disability insurance | RI | Often treated as a state income tax item on Schedule A |
| HISDI | State Disability Insurance | HI | Often treated as a state income tax item on Schedule A |
| WASDI / WA PFML | Paid family and medical leave | WA | Often treated as a state income tax item on Schedule A |

## Common informational-only items

| Code | Description | Typical treatment |
|---|---|---|
| Code D | 401(k) elective deferrals | Informational; already reflected through wage reporting |
| Code W | HSA employer or cafeteria-plan amounts | Usually handled through Form 8889 and Box 12 |
| Code DD | Employer-sponsored health coverage cost | Informational only |
| GT / GTL | Group-term life insurance | Often already reflected in wages if taxable |
| RHS / Roth | Roth contributions | Informational |
| UNION | Union dues | Generally not deductible on a federal return for 2025 |
| Moving | Employer-paid moving expenses | Usually not deductible unless a military exception applies |
