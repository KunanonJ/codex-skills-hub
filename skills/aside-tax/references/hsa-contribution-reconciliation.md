# HSA Contribution Reconciliation: W-2 Code W vs. Form 5498-SA

When a taxpayer has both W-2(s) with Box 12 Code W and a Form 5498-SA, reconcile the amounts before completing Form 8889 Part I. Incorrect allocation between Lines 2 and 9 can trigger the 6% excess contribution penalty under IRC 4973.

## What each document reports

- **W-2 Box 12, Code W** — combined total of employer contributions AND employee pre-tax contributions made through a cafeteria plan (Section 125 salary reduction). This is the Line 9 amount (after any timing adjustments via the Employer Contribution Worksheet).
- **Form 5498-SA Box 2** — total contributions the HSA trustee received during the year from all sources: employer, cafeteria plan, and direct personal contributions.

## Reconciliation

```
1. Sum W-2 Code W from ALL the taxpayer's W-2s ......... ________

2. Form 5498-SA Box 2 (total contributions) ............ ________

3. Subtract line 1 from line 2.
   This is the taxpayer's direct personal
   contributions for Form 8889 Line 2 .................. ________
```

If line 3 is negative, the taxpayer may have made prior-year contributions reported on the current 5498-SA, or there is a data error — investigate before proceeding.

## Common scenarios

| Scenario | Result |
|---|---|
| Only cafeteria-plan contributions (no personal) | 5498-SA Box 2 = sum of W-2 Code W; Line 2 = $0 |
| Cafeteria-plan + direct personal contributions | 5498-SA Box 2 > sum of W-2 Code W; difference is Line 2 |
| Multiple employers with HSA contributions | Sum all W-2 Code W amounts; compare to 5498-SA Box 2 |
| Contributions made in January–April for prior year | Employer Contribution Worksheet timing adjustment applies; 5498-SA may not match current-year W-2 Code W |

## When to investigate further

- 5498-SA Box 2 is less than the sum of W-2 Code W (suggests timing mismatch or data error)
- The taxpayer cannot explain the difference between the two figures
- Total contributions (5498-SA Box 2) exceed the annual limit ($4,300 self-only / $8,550 family for 2025) — check for excess contributions
