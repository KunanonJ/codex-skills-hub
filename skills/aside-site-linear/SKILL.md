# Linear

## Canonical URLs

- New issue: `https://linear.new`
- New issue: `https://linear.app/new`
- Team-scoped new issue: `https://linear.app/team/${teamId}/new`

## Working style

- Linear is keyboard-first. Prefer create links, command search, and direct issue links.
- Reuse the signed-in session and avoid guessing deep URLs for existing work.
- For existing issues or projects, stay on the current issue or project page and edit in place.

## Useful shortcuts

- Global search: `/`
- Recent issues or issue search: `O`, then `I`
- Inbox: `G`, then `I`
- Command menu: `Cmd/Ctrl+K`
- Search current view: `Cmd/Ctrl+F`
- Toggle project details: `Cmd/Ctrl+I`
- Create issue: `C`
- Fullscreen issue composer: `V`
- Edit current issue: `E`
- Project documents: `O`, then `D`
- Snooze inbox item: `H`
- Unsubscribe from issue in inbox: `Shift+S`
