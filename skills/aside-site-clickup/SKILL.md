# ClickUp

## Canonical URLs

- Login: `https://app.clickup.com/login`

## Working style

- ClickUp is session-based. Keep the same tab after auth.
- If links try to jump to the desktop app, disable `Detect Desktop App` in settings or keep the desktop app closed.
- Prefer search and command-bar navigation over deep sidebar browsing.
- For a specific task, copy and reuse the current task URL instead of guessing from IDs.

## Useful shortcuts

- Home: `H`
- Inbox: `I`
- Dashboards: `D`
- List / board / calendar view: `L`, `B`, `C`
- Team view: `X`
- Search or command bar: `S` or `Cmd/Ctrl+K`
- Create task: `T`
- Close task or window: `Escape`
- Change status: `Shift+S`
- Comment: `Shift+M`
- Due date: `Shift+D`
- Assignee: `Shift+A`
- Assign to self: `M`
- Subtask: `Shift+T`
- Priority: `Shift+P`
- Timer: `Shift+.`
- List navigation: `Ctrl+Shift+Left/Right`

Inbox shortcuts:

- All tab: `Shift+A`
- Primary or important: `Shift+P` on 4.0, `Shift+I` on 3.0
- Other / snoozed / cleared: `Shift+O`, `Shift+Z`, `Shift+C`
- Open notification: `O` or `Enter`
- Next / previous notification: `J`, `K`
- Details sidebar: `]`
- Refresh inbox: `Space`
- Clear / unclear: `E`
- Snooze: `Z`
- Mark unread / read: `U`
